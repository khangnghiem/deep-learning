## 2024-05-24 - PyTorch Dataset Iteration Bottleneck
**Learning:** Iterating over a PyTorch `Dataset` using standard Python iteration (`for item in dataset:`) relies on catching a `StopIteration` or `IndexError` at the end of the sequence. This triggers an extra, unnecessary out-of-bounds `__getitem__` call, which can cause redundant I/O and expensive augmentations. Additionally, calling `__getitem__` multiple times across different methods (e.g. to get labels then get weights) multiplies this expensive operation.
**Action:** When extracting properties like labels from a dataset, use explicit index iteration (`for i in range(len(dataset)): item = dataset[i]`). Also, extract all required properties (like labels and class weights) in a single pass to prevent redundant, expensive operations.
