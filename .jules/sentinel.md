## 2024-05-24 - [CRITICAL] Prevent Command Injection via os.system Downloads
**Vulnerability:** Found `os.system(f"wget ... -O {PATH}")` used for downloading a model checkpoint in an evaluation script. This is highly susceptible to shell command injection if `PATH` is ever dynamically constructed or manipulated, even when initialized as a `Path` object in Python.
**Learning:** Shell evaluation (`os.system` or `subprocess.Popen(shell=True)`) combined with formatted strings for arguments is an anti-pattern. While `PATH` might currently be static, its structure could be altered by configuration changes or environment variables, posing a serious command injection risk in production or CI/CD pipelines.
**Prevention:** Avoid `os.system()` and `shell=True` for system commands, especially those involving I/O paths. Use robust native Python libraries like `urllib.request.urlretrieve` or `requests.get` for HTTP downloads. If a subprocess is strictly necessary, always use `subprocess.run` with a list of arguments (e.g., `["wget", "-q", url, "-O", str(path)]`) to ensure proper shell escaping.
