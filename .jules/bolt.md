## 2025-05-18 - Optimized Dataset Iteration in create_imbalanced_sampler
**Learning:** I found that `create_imbalanced_sampler` was iterating through the dataset twice, once via `get_class_weights` to calculate weights and again to construct the `sample_weights` array. Furthermore, iterating directly over the dataset `for item in dataset:` caused an extra I/O/access due to the final iteration checking for `StopIteration`.
**Action:** Always pre-calculate required properties from datasets (like labels) in a single pass using `range(len(dataset))` instead of iterator protocols to avoid redundant I/O operations and augmentations, especially on expensive dataset accesses. Refactored utilities to accept these pre-calculated values and used advanced tensor indexing (`class_weights[torch.as_tensor(labels)]`) to map them safely.
