## 2024-06-27 - Optimize WeightedRandomSampler Initialization
**Learning:** Initializing `WeightedRandomSampler` using helper functions like `get_class_weights` can unintentionally result in iterating over the entire dataset multiple times (once for class statistics, once for sample weight mapping). Since `Dataset.__getitem__` can be an expensive operation (e.g., involving I/O or transformations), this double pass is a significant bottleneck.
**Action:** Always compute necessary dataset statistics in a single pass. When mapping class weights to sample weights in PyTorch, prefer extracting labels into a list during the single pass and utilizing advanced tensor indexing (e.g., `sample_weights = class_weights[labels]`) instead of looping, appending to a list, and converting to a tensor.
