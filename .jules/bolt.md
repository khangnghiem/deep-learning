## 2024-05-18 - Avoid double dataset passes in DataLoader Initialization
**Learning:** PyTorch DataLoader initializations like `WeightedRandomSampler` often require iterating over the dataset to calculate frequencies. Iterating a second time to map these frequencies back to individual samples introduces a massive bottleneck if `__getitem__` involves expensive I/O operations (like reading images from disk). PyTorch allows advanced tensor indexing using standard Python lists, meaning we can map a tensor of weights directly against a list of labels in one rapid operation without a loop.
**Action:** Always compute both class statistics and sample mappings in a single dataset pass during initialization. Avoid list comprehension conversions like `torch.tensor([class_weights[lbl] for lbl in labels])` and use `class_weights[labels]` instead.
