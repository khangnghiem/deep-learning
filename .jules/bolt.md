## 2024-06-13 - Avoid Multiple Dataset Traversal During Sampler Initialization
**Learning:** During dataset splitting/loader creation, some utilities (like `get_class_weights` and `create_imbalanced_sampler`) compute statistics by iterating over the dataset multiple times. This introduces redundant performance bottlenecks when dataset iteration (`__getitem__`) performs expensive transformations or disk I/O, scaling worst-case traversal times linearly with large datasets (O(2N) instead of O(N)).
**Action:** When initializing samplers or determining dataset-level metrics (e.g., class distribution), compute relevant metrics and statistics utilizing single-pass iterations by extracting target data once up-front (e.g., generating an initial label map array). Additionally, ensure utilities like `get_class_weights` are modular and accept a precomputed payload to prevent redundant logic execution.
